API de Cadastro de Clientes e Produtos — Django

Este projeto é uma API REST desenvolvida com Django e Django Rest Framework para gerenciamento de clientes e produtos, criada com foco em aprendizado prático, organização de código e portfólio profissional.

 Objetivo do Projeto

Desenvolver uma API backend que permita:
- Cadastro, listagem, edição e exclusão de clientes
- Cadastro, listagem, edição e exclusão de produtos
- Estrutura organizada seguindo boas práticas do Django
- Base para integração com um frontend futuramente (React, Vue, etc.

 Tecnologias Utilizadas

- Python
- Django
- Django Rest Framework
- SQLite (banco de dados padrão)
- Git & GitHub


 Funcionalidades

 Clientes
- Criar cliente
- Listar clientes
- Atualizar dados do cliente
- Excluir cliente
